# Assets

Put your own files here. `<id>` is one of `hl2`, `hl2-1`, `hl2-2`, `portal`, `tf2`.

```
assets/
├── logo.png               top-center logo
├── <id>.jpg               static image on the button (.png / .webp also work)
├── <id>.mp4               full-window background video
├── trailers/
│   └── <id>.mp4           trailer shown inside the button
└── key/
    ├── enter.png          keyboard prompt
    ├── x.png              PlayStation prompt (PS3 / PS4 / PS5)
    └── a.png              Xbox prompt
```

Optional: `icon.png` (512x512) is used as the window icon.

Use H.264 (`.mp4`) videos. Missing files are skipped without errors.
